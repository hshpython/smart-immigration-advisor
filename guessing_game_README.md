# 🎮 Number Guessing Game

A simple Python game where the player tries to guess a random number.

## Features

- Random number generation (1-100)
- 10 attempts limit
- Smart hints (Too high / Too low)
- Input validation
- Play again option

## How to Run

```bash
python guessing_game.py

How to Play
The program selects a random number between 1 and 100

You have 10 attempts to guess it

After each guess, you'll get a hint:

📉 Too low!

📈 Too high!

Win by guessing the correct number
